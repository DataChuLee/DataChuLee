# Tech badge sources

All badges are 28 px high, self-contained SVGs. Brand artwork is scaled proportionally. Official lockups keep their supplied colors and wordmarks; the white badge background provides contrast on light and dark GitHub themes.

- LangChain and LangGraph: official **open-source framework** lockups, light variants, downloaded from https://www.langchain.com/brand-assets and its linked archive https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6a9998494f7b532d49a38525_langchain-brand-assets.zip . These are distinct from the company and community logos.
- LangSmith: official wordmark https://cdn.prod.website-files.com/65b8cd72835ceeacd4449a53/6a9936e524dccd963978bf0f_LangSmith_Wordmark_Black%201.svg .
- Chroma: official website wordmark https://www.trychroma.com/_next/static/immutable/media/chroma-wordmark.3omc55d6a9e1l.svg .
- Codex: Lobe Icons Codex symbol, cross-checked against the cloud/terminal symbol displayed on https://openai.com/codex/ .
- OpenAI API: OpenAI symbol from Lobe Icons.
- Claude Code: Simple Icons `claudecode` symbol (the pixel mascot), replacing the generic Claude symbol.
- Python, FastAPI, PostgreSQL, MySQL, Redis, Docker, Git and GitHub: Simple Icons.
- **FAISS** uses Tabler's generic `vector` symbol; it is a visual cue for vector search, **not an official FAISS logo**.
- **BM25** uses Tabler's generic `search` symbol; it represents keyword retrieval, **not a product logo**. BM25 is a ranking algorithm.

The icons identify tools used by the profile owner; they do not imply sponsorship or endorsement. All brand marks belong to their respective owners.
